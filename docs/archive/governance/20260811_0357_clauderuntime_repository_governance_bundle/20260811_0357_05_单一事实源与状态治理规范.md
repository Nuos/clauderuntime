# ClaudeRuntime 单一事实源与状态治理规范

## 1. 当前需要解决的问题

同一种信息如果同时存在于：

```text
README
CHANGELOG
NEWS
FEATURE_LIST
TODOS
development-progress
diagnostic
parity maps
GitHub Issues
```

就会产生：

- 旧状态长期残留；
- Agent 读取错误；
- Contributor 不知道哪个是真的；
- 同一功能出现“已完成/未完成”并存；
- 文档维护成本持续增长。

---

## 2. 单一事实源定义

### 产品入口
**真值源：`README.md`**

只负责：

- 产品是什么；
- 如何安装；
- 快速使用；
- 当前主要能力；
- 链接到详细文档。

不承担完整 Roadmap。

### 发布历史
**真值源：`CHANGELOG.md`**

只记录版本级正式变化。

### 新闻长历史
**真值源：`docs/history/NEWS.md`**

README 仅保留最近少量新闻。

### 当前系统架构
**真值源：`docs/architecture/`**

禁止旧 FEATURE_LIST 或研究 Wiki 作为当前架构说明。

### Claude Code Parity
**真值源：`docs/parity/`**

机器可读资产优先于散文：

```text
source maps
runtime maps
aux loop maps
scorecards
divergence registry
```

### 当前开发状态
**真值源：`docs/status/current.md`**

只保留当前状态。

### 当前剩余高层缺口
**真值源：`docs/status/backlog.md`**

### 可执行工作项
**真值源：GitHub Issues**

不再使用根目录 TODO 作为长期任务管理系统。

### 历史进度
**真值源：`docs/progress/`**

只用于追溯，不覆盖 current status。

### 失效历史
**真值源：`docs/archive/`**

---

## 3. 冲突优先级

当文档发生冲突时：

```text
当前源码 + 当前测试
    >
机器可读 Parity Map
    >
docs/status/current.md
    >
docs/architecture/
    >
active plan
    >
progress history
    >
archive
    >
旧 README/Feature/TODO 描述
```

任何诊断必须遵守这一优先级。

## 5. Backlog 文件建议格式

`docs/status/backlog.md` 只保留高层差距，不复制 GitHub Issues 全文。

```markdown
| ID | Component | Layer | AUX | Priority | Issue |
|---|---|---|---|---|---|
| EX-01 | Execution | L3 | AUX-02 | P0 | #xxx |
```

---

## 6. 禁止重复真值

禁止重新创建：

```text
FEATURE_LIST_V2.md
TODO_NEW.md
CURRENT_STATUS_2.md
ARCHITECTURE_NEW.md
PARITY_NOTES_FINAL.md
```

如果已有正式类别，应更新对应真值源。

---

## 7. 自动治理建议

后续可增加 CI 检查：

- 根目录 Markdown 白名单；
- docs 一级目录白名单；
- Markdown broken link；
- `status/current.md` 的 reference commit 是否过期；
- machine-readable parity map schema；
- Critical AUX 是否存在；
- UNKNOWN critical path 数量；
- archive 文档是否被误链为 current。
