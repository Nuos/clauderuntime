# B6 最终验收清单

# A. 核心功能

- [ ] 普通 Agent query 可稳定完成
- [ ] Read / Write / Edit / Bash / Grep / Glob 可用
- [ ] Permission deny / allow / ask 可用
- [ ] Tool failure 能回到 Agent loop
- [ ] Context instructions 可加载
- [ ] Path-scoped rules 可延迟注入
- [ ] 长上下文有预算/压缩机制
- [ ] Transcript 可持久化
- [ ] Background Agent 可运行
- [ ] Resume 常见场景可恢复
- [ ] MCP 可连接、发现、执行、清理
- [ ] Hooks 关键事件可运行并超时清理
- [ ] Scheduler 基础 create/list/delete/fire/restore 可用
- [ ] Interrupt/abort 能停止主要执行路径

# B. 安全底线

- [ ] Permission deny 不可绕过
- [ ] background execution 不成为安全旁路
- [ ] required isolation 不可静默退化
- [ ] stale MCP tools 不可继续调用
- [ ] Resume 不恢复 API key / 临时权限
- [ ] timeout 后危险 child process 不继续执行
- [ ] symlink/path escape 有明确处理

# C. Reference 分级对齐

- [ ] R1_CONFIRMED 项已按 MUST_ALIGN 验收
- [ ] R2_PARTIALLY_CONFIRMED 项的已知 contract/gate/control 已对齐
- [ ] R3_UNKNOWN 项没有伪造 Reference 实现细节
- [ ] R4_PRODUCT_EXTENSION 与 Reference 能力明确分离
- [ ] 已知偏离都具有明确原因和影响评估

# D. 差异透明

- [ ] 所有新增/重大修改核心模块有 Reference Mapping
- [ ] 关键不同函数有 REF-DIFF
- [ ] 全局 difference registry 已更新
- [ ] progress 文档有 Reference vs Python 差异
- [ ] UNKNOWN Reference 没有被写成确定事实
- [ ] accepted divergence 有明确原因

# D. 平台与 Surface

- [ ] macOS execution boundary smoke
- [ ] Linux capability / fallback 说明真实
- [ ] Windows capability / fallback 说明真实
- [ ] CLI smoke
- [ ] TUI smoke
- [ ] Server smoke
- [ ] Desktop smoke（若正式支持）
- [ ] IDE smoke（若正式支持）

# E. 测试

- [ ] targeted tests 通过
- [ ] affected combination tests 通过
- [ ] 阶段收尾 full local suite 通过
- [ ] 外部依赖测试结果单独记录
- [ ] GitHub CI 若启用，结果与 local 分开记录

# Final

只有 A/B/C 的核心项全部满足，才允许：

```text
FUNCTIONALLY_SIMILAR_CORE_COMPLETE
```

D 中受平台限制的项目可以是 `LIMITED`，但必须真实披露。
